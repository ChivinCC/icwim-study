# ICWIM 随身练习室

英文作答、中文题意与解析摘要的个人备考工具。174 道题来自用户提供的第三方练习资料，含重复题，部分答案已标疑；非 CISI 官方题库。

## 使用

直接打开 index.html，或通过 GitHub Pages 访问。不需要安装或构建。

- 逐题练习：提交后查看原答案、中文题意、选项及解析摘要。
- 模拟考试：默认100题、120分钟，交卷后复盘。
- 收藏、待复习标记、错题重练、进度导入导出。
- 手机布局；刷新后恢复未完成场次及已选答案。

## 进度

使用浏览器 localStorage 保存；同一网址、同一浏览器刷新后可继续。清除网站数据、无痕模式、更换浏览器或设备不保证保留。不是云端同步。旧本地页面与 Pages 网址的存储独立，可从旧页面导出记录，到新页面导入。

模拟考试倒计时包含离开页面的时间，截止后自动交卷。

## GitHub Pages

在仓库 Settings → Pages 中从 main 分支根目录发布。私有仓库的 Pages 可用性依账户套餐；Pages 网站访问权限与仓库私有状态并非一回事。

## 内容范围

仅上传网站文件，不上传原始 PDF、个人答题记录、私钥或服务器凭据。保留第三方题库原答案，中文为学习摘要，不代表官方校订。未授予第三方题库内容的再分发许可。
